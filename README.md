# Card Updater — SillyTavern extension

อัปเดตการ์ดตัวละครที่แก้แล้วในครั้งเดียว ไม่ต้องเช็คหลายหน้าต่าง

- **แชทเดิมยังเชื่อมอยู่** — เขียนทับการ์ดโดยใช้ชื่อไฟล์เดิม (ใช้กลไกเดียวกับ Replace / Update ของ SillyTavern)
- **ไม่ต้องเปลี่ยนเวอร์ชัน lorebook อีก** — เขียน lorebook ที่ฝังในการ์ดทับ lorebook ชื่อเดิมที่ผูกอยู่ แล้วผูกกับการ์ดให้เลย SillyTavern จึงไม่ดึงของเก่ามาใช้
- **Regex ไม่ต้องไปติ๊กเอง** — อนุญาต regex ของการ์ดให้อัตโนมัติ บอกว่ามีกี่ตัว ตัวไหนเพิ่มมาใหม่ ตัวไหนหายไป และถ้าไฟล์ใหม่ไม่มี regex เลย ก็ใส่ของเดิมกลับให้ได้
- **การ์ด .json ใช้รูปเดิม** — ปกติถ้าอัปเดตด้วย .json รูปจะกลายเป็นรูปเริ่มต้น ตัวนี้เอารูปเดิมมาใช้ต่อ
- **สรุปผลในหน้าต่างเดียว** และมีปุ่ม **ย้อนกลับ** ถ้าเลือกไฟล์ผิด
- **ใช้บน iPhone / iPad ได้** — ปุ่ม Replace / Update เดิมของ SillyTavern เปิดหน้าเลือกไฟล์บน iOS ไม่ได้ แต่ปุ่มของ extension นี้เปิดได้

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

1. เปิดตัวละครที่จะอัปเดต
2. ในแผงตัวละคร กดปุ่ม <kbd>⬆ ไฟล์</kbd> (ไอคอนไฟล์ลูกศรขึ้น ข้างปุ่ม Export) หรือไปที่ Extensions → Card Updater → **อัปเดตการ์ดที่เปิดอยู่…**
3. เลือกไฟล์การ์ดที่แก้แล้ว (.png .json .charx .yaml .byaf)
4. ดูหน้าต่างก่อนอัปเดต แล้วกด **อัปเดต**
5. อ่านสรุป — ถ้าผิดกด **ย้อนกลับ**

### หน้าต่างก่อนอัปเดตบอกอะไรบ้าง

| ส่วน | รายละเอียด |
|---|---|
| ไฟล์ | ไฟล์ที่เลือก → ชื่อไฟล์การ์ดที่จะเขียนทับ · ถ้า**ชื่อตัวละครในไฟล์ไม่ตรง**จะเตือน (กันเลือกผิดไฟล์) |
| Lorebook | จำนวน entries ในการ์ด · ช่อง**ชื่อ lorebook ที่จะเขียนทับ** (ค่าเริ่มต้นคือตัวที่ผูกอยู่ตอนนี้) · บอกว่ามีอยู่แล้ว (เขียนทับ) หรือยังไม่มี (สร้างใหม่) |
| Regex | จำนวนในไฟล์เทียบกับของเดิม · อนุญาตให้ทำงาน · ใส่ของเดิมกลับถ้าไฟล์ใหม่ไม่มี |
| รูป (.json) | ใช้รูปตัวละครเดิม |

ตัวเลือกที่เลือกไว้จะถูกจำเป็นค่าเริ่มต้นของครั้งถัดไป (แก้ได้ที่ Extensions → Card Updater ด้วย)

### เลิกตั้งชื่อ lorebook แบบมีเวอร์ชัน

ถ้าตอนนี้ lorebook ชื่อ `Reisei Lore v7` อยู่ ตอนอัปเดตครั้งหน้าให้แก้ช่องชื่อเป็นชื่อถาวร เช่น `Reisei Lore` extension จะสร้าง lorebook ชื่อใหม่แล้วผูกกับการ์ดให้ หลังจากนั้นช่องจะเติมชื่อนี้ให้เองทุกครั้ง ส่วนเวอร์ชันเก่า ๆ ที่ค้างอยู่ลบเองได้ในหน้า World Info

## ข้อควรรู้

- **บน iPhone ให้เลือกไฟล์จากแอป Files ไม่ใช่คลังรูปภาพ (Photos)** เพราะ Photos ลบข้อมูลการ์ดที่ฝังในรูป PNG ทิ้ง ถ้าเผลอเลือกจาก Photos extension จะเตือนและไม่อัปเดต
- lorebook ถูก**เขียนทับทั้งเล่ม**ด้วยเนื้อหาจากการ์ด ถ้าเคยแก้ entry ใน SillyTavern โดยตรงแต่ไม่ได้แก้ในการ์ด ส่วนนั้นจะหาย (ย้อนกลับได้ในหน้าสรุป)
- ถ้า lorebook เดียวกันผูกกับหลายตัวละคร ทุกตัวจะเห็นเนื้อหาใหม่
- ปุ่ม **ย้อนกลับ** ใช้ได้เฉพาะในหน้าสรุปหลังอัปเดต ปิดหน้าสรุปแล้วย้อนไม่ได้ · ถ้าการอัปเดตสร้าง lorebook ชื่อใหม่ ตอนย้อนกลับ lorebook นั้นยังอยู่ (ลบเองได้)
- ใช้กับแชทกลุ่มไม่ได้ ต้องเปิดตัวละครเดี่ยว · ถ้าบอทกำลังตอบอยู่ ให้รอหรือกดหยุดก่อน
- ไฟล์ .yaml ไม่มีรูป รูปตัวละครจะกลายเป็นรูปเริ่มต้น
- ทดสอบกับ SillyTavern 1.19.0
