# Card Updater — SillyTavern extension

อัปเดตการ์ดตัวละคร, lorebook และ regex ที่แก้แล้วในครั้งเดียว ไม่ต้องเช็คหลายหน้าต่าง

เลือกไฟล์อะไรมาก็ได้ extension จะดูให้เองว่าไฟล์ไหนเป็นอะไร และเลือกหลายไฟล์พร้อมกันได้ เช่น การ์ด + lorebook + regex

| เลือกไฟล์ | สิ่งที่เกิดขึ้น |
|---|---|
| **การ์ดตัวละคร** (.png .json .charx .yaml .byaf) | เขียนทับการ์ดที่เปิดอยู่โดย**ใช้ชื่อไฟล์เดิม** แชทเดิมยังเชื่อมอยู่ครบ · lorebook ที่ฝังในการ์ดเขียนทับเล่มที่ผูกอยู่ (ชื่อเดิม) หรือเลือก**สร้างเล่มใหม่ที่มีเลขเวอร์ชัน**ก็ได้ · regex ในการ์ดแทนตัวชื่อซ้ำ ตัวเดิมที่การ์ดไม่มีคงไว้ · อนุญาต regex ของการ์ด · การ์ด .json ใช้รูปเดิม |
| **lorebook** (.json แบบที่ export จาก World Info ของ ST หรือ character_book V2) | เขียนทับ lorebook ที่ผูกกับการ์ดอยู่ (หรือเล่มไหนก็ได้ที่พิมพ์ชื่อ) หรือสร้างเป็นเล่มใหม่ที่มีเลขเวอร์ชัน · บอกว่าต่างจากของเดิมกี่ entry · ใส่ lorebook ใหม่เข้าไปในการ์ดด้วย เวลา export การ์ดจะได้เล่มล่าสุดติดไป |
| **regex** (.json ตัวเดียว หรือหลายตัวในไฟล์เดียว) | แทนตัวที่**ชื่อซ้ำ**และเพิ่มตัวใหม่ ตัวอื่นคงไว้ (หรือเลือกแทนทั้งชุด) ใส่ใน regex ของการ์ด หรือ global regex ก็ได้ |
| **การ์ดที่มีสคริปต์ Tavern Helper** (JS-Slash-Runner) หรือมี `card_updater` manifest | **ไม่ import ทับทั้งใบ** แต่อัปเดตทีละส่วน ความคืบหน้าในแชท ตัวแปร และค่าที่ผู้เล่นตั้งไว้คงเดิม (ดูหัวข้อด้านล่าง) |

ก่อนอัปเดตจะมีหน้าต่างให้ดูว่าจะเกิดอะไรขึ้น หลังอัปเดตมีหน้าสรุป พร้อมปุ่ม **ย้อนกลับ** ถ้าเลือกผิด

ใช้บน iPhone / iPad ได้ ปุ่ม Replace / Update เดิมของ SillyTavern เปิดหน้าเลือกไฟล์บน iOS ไม่ได้ แต่ปุ่มของ extension นี้เปิดได้

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

1. เปิดตัวละคร
2. กดปุ่ม <kbd>⬆ ไฟล์</kbd> ในแผงตัวละคร (ไอคอนไฟล์ลูกศรขึ้น ข้างปุ่ม Export) หรือไปที่ Extensions → Card Updater → **เลือกไฟล์อัปเดต…**
3. เลือกไฟล์ ถ้าจะเลือกหลายไฟล์ในแอป Files ของ iPhone ให้กด **เลือก (Select)** มุมขวาบนก่อน
4. ดูหน้าต่างก่อนอัปเดต แล้วกด **อัปเดต**
5. อ่านสรุป ถ้าผิดกด **ย้อนกลับ**

ถ้าไม่ได้เปิดตัวละครไว้ (หรืออยู่ในแชทกลุ่ม) ปุ่มใน Extensions → Card Updater ยังอัปเดต lorebook กับ global regex ได้ แต่อัปเดตการ์ดไม่ได้

### Lorebook

- **วิธีอัปเดต** เลือกได้ 2 แบบ (จำค่าที่เลือกล่าสุดไว้ ตั้งค่าเริ่มต้นได้ใน Extensions → Card Updater)
  - *เขียนทับเล่มเดิม* (ค่าเริ่มต้น) ช่องชื่อจะเติมชื่อเล่มที่ผูกกับการ์ดอยู่ให้ ถ้าจะเขียนเล่มอื่นก็พิมพ์ชื่อได้ (ไม่มีเล่มชื่อนั้นก็จะสร้างใหม่)
  - *สร้างเล่มใหม่ มีเลขเวอร์ชัน* เล่มเดิมคงไว้ไม่แตะ ใช้เป็นสำรองหรือเทียบกันได้ เล่มใหม่จะผูกกับการ์ดแทน (เอาติ๊ก "ผูกเป็น lorebook หลัก" ออกได้) ชื่อจะเติมให้ตามกฎด้านล่าง แก้เองได้ แต่ต้องไม่ซ้ำกับเล่มที่มีอยู่
- **ชื่อเล่มใหม่:** เอาชื่อเล่มเดิมตัดเลขเวอร์ชันท้ายชื่อออก แล้วต่อด้วยเวอร์ชันใหม่
  - เวอร์ชันมาจากชื่อไฟล์ lorebook (`..._v0.6.json`) ถ้าไม่มีก็ใช้ของการ์ด (`card_updater.version` หรือ `character_version`) เช่น `คำให้การ — คดี` → `คำให้การ — คดี v0.5.2`, `Book v0.5.1` → `Book v0.5.2`
  - ไม่รู้เวอร์ชัน → รันเลขต่อจากเล่มที่มีอยู่ `Book` → `Book v2`, `Book v3` → `Book v4`
  - ถ้าชื่อนั้นมีอยู่แล้ว (เช่นอัปเดตเวอร์ชันเดิมซ้ำ) ต่อท้าย `(2)`, `(3)`…
- จะบอกว่าต่างจากของเดิมยังไง เช่น `ใหม่/แก้ 3 · ของเดิมที่ไม่อยู่ในของใหม่ 1 · เหมือนเดิม 40`
- **กันของเก่าทับของใหม่:** ถ้าครั้งล่าสุดอัปเดต lorebook จากไฟล์ lorebook แยก แล้วตอนนี้อัปเดตการ์ดที่ฝัง lorebook ที่ต่างออกไป ช่องเขียนทับ lorebook จะไม่ติ๊กไว้ให้และมีคำเตือน เพราะของในการ์ดน่าจะเก่ากว่า ถ้าอยากเขียนทับจริงก็ติ๊กเองได้
- ถ้าเลือกการ์ดกับไฟล์ lorebook มาพร้อมกัน จะใช้ไฟล์ lorebook แทนของที่ฝังในการ์ด

### Regex

- **ใส่ไว้ที่:** regex ของการ์ด หรือ global ค่าเริ่มต้นจะดูจากชื่อ ถ้าชื่อในไฟล์ไปตรงกับ global regex ก็เลือก global ให้ ไม่อย่างนั้นใส่ในการ์ด
- **วิธีใส่:**
  - *แทนตัวชื่อซ้ำ + เพิ่มตัวใหม่* (ค่าเริ่มต้น) ตัวที่ชื่อซ้ำถูกแทนในตำแหน่งเดิม ตัวที่ไม่อยู่ในไฟล์คงไว้
  - *แทนทั้งชุด* ตัวที่ไม่อยู่ในไฟล์จะถูกลบ (หน้าต่างจะบอกชื่อก่อน)
- ตัวที่ปิดไว้ (disabled) ในไฟล์ จะปิดอยู่เหมือนในไฟล์
- **อัปเดตการ์ด:** regex ในการ์ดใหม่จะแทนตัวที่ชื่อซ้ำ ตัวเดิมที่การ์ดใหม่ไม่มีจะ**คงไว้** (เช่น การ์ดเดิมมี 7 ตัว การ์ดใหม่มีแค่ 2 ตัวที่แก้ ก็ยังได้ครบ 7 ตัว) ถ้าอยากให้ลบตัวที่การ์ดใหม่ไม่มี เลือก *ลบทิ้ง* ในหน้าต่างก่อนอัปเดต ซึ่งจะบอกชื่อตัวที่จะคงไว้/ลบก่อน

### การ์ดที่มีสคริปต์ Tavern Helper

ถ้าการ์ดมีสคริปต์ Tavern Helper (`data.extensions.tavern_helper`) หรือมี manifest `data.extensions.card_updater` จะอัปเดตแบบทีละส่วนแทนการ import ทับ

| ส่วน | เขียนทับจากการ์ดใหม่ | คงค่าของผู้เล่น |
|---|---|---|
| สคริปต์ (จับคู่ด้วย `id` ค้นในโฟลเดอร์ด้วย) | `content` `info` `name` ชื่อปุ่ม | เปิด/ปิด, `data`, `export_with`, การแสดงปุ่ม · สคริปต์อื่นของผู้เล่นไม่แตะ |
| Regex (จับคู่ด้วย `id`) | pattern, replace, placement และตัวเลือกอื่น | เปิด/ปิด · regex อื่นของผู้เล่นไม่แตะ |
| Lorebook ที่ฝังในการ์ด | ทั้งชุด | — |
| ไฟล์ lorebook ที่ผูกไว้ (จับคู่ด้วยชื่อ entry) | เฉพาะ entry ใน `owned_entries` | `uid` และเปิด/ปิด · entry ที่ผู้เล่นเพิ่มเองไม่แตะ · เลือก *สร้างเล่มใหม่* ได้: ก็อปเล่มเดิมแล้วอัปเดตในเล่มใหม่ (entry ของผู้เล่นติดไปด้วย) ผูกเล่มใหม่แทน เล่มเดิมคงไว้ |
| ข้อมูลการ์ด | description, first_mes, creator_notes, tags, character_version ฯลฯ | ชื่อตัวละคร, การผูก lorebook |

- entry ใน `force_disabled` จะถูก**ปิดเสมอ**หลังอัปเดต (เช่น entry ที่เก็บเฉลย)
- entry ที่การ์ดเดิมเป็นเจ้าของแต่การ์ดใหม่ไม่มีแล้ว จะถามก่อนลบ (ไม่ติ๊กไว้ให้)
- **ไม่แตะ:** ตัวแปรในแชท (ความคืบหน้าในเกม), ตัวแปรระดับการ์ด (`tavern_helper.variables`), การอนุญาตสคริปต์และ regex ของการ์ด
- การ์ดที่เปิดอยู่เขียนผ่าน API ของ Tavern Helper สคริปต์รีโหลดเอง ไม่ต้องรีเฟรชหน้า · การ์ดที่ไม่ได้เปิดก็อัปเดตได้ (ถ้าไม่ได้เปิดตัวละครไว้ จะหาตัวละครที่ `bot_id` หรือชื่อตรงกันให้ ถ้ามีหลายตัวจะให้เลือก)
- `bot_id` ไม่ตรงกัน → ไม่อัปเดต · เวอร์ชันในไฟล์ไม่ได้ใหม่กว่า → ถามก่อน
- การ์ดเดิมที่ไม่มี manifest จะจับคู่ด้วยชื่อ (มีคำเตือน) แล้วรับ `id` ของการ์ดใหม่ไป ครั้งต่อไปจับคู่ด้วย `id` ได้
- ไม่ได้ติดตั้ง JS-Slash-Runner ก็อัปเดตได้ แต่จะเตือนให้ติดตั้งก่อนเล่น
- การ์ด .png เลือกได้ว่าจะใช้รูปจากการ์ดใหม่หรือไม่ · เลือกการ์ดแบบนี้ได้ทีละไฟล์ (ไม่ต้องเลือก lorebook/regex แยก)

#### Manifest สำหรับผู้สร้างการ์ด

```json
"card_updater": {
  "schema": 1,
  "bot_id": "kamhaikan",
  "version": "0.1.3",
  "tavern_helper_scripts": ["<id คงที่ของสคริปต์>"],
  "regex_scripts": ["<id คงที่ของ regex>"],
  "lorebook": { "owned_entries": ["กฎผู้บรรยาย", "CASE:case01"], "force_disabled": ["CASE:case01"] }
}
```

ใช้ id ที่คงที่ทุกบิลด์ (เช่น `uuid5`) ห้ามสุ่มใหม่ทุกเวอร์ชัน

### ใช้ lorebook ชื่อเดียว หรือแยกเล่มตามเวอร์ชัน

- **ชื่อเดียวตลอด:** เลือก *เขียนทับเล่มเดิม* ถ้าตอนนี้ชื่อมีเลขเวอร์ชันติดอยู่ ให้ rename ใน World Info ของ SillyTavern (ปุ่มดินสอ) แล้วกด **Yes** ตอนถามว่าจะอัปเดตการผูกของตัวละครไหม หลังจากนั้น Card Updater จะเติมชื่อนั้นให้เองทุกครั้ง
- **แยกเล่มตามเวอร์ชัน:** เลือก *สร้างเล่มใหม่ มีเลขเวอร์ชัน* ทุกครั้งที่อัปเดตจะได้เล่มใหม่ เล่มเก่าค้างอยู่ใน World Info ลบเองได้เมื่อไม่ใช้แล้ว

## ข้อควรรู้

- **บน iPhone ให้เลือกการ์ดจากแอป Files ไม่ใช่คลังรูปภาพ (Photos)** เพราะ Photos ลบข้อมูลการ์ดที่ฝังในรูป PNG ทิ้ง ถ้าเลือกจาก Photos extension จะเตือนและไม่อัปเดต
- แบบ *เขียนทับเล่มเดิม* lorebook ถูก**เขียนทับทั้งเล่ม** entry ที่เคยแก้ใน SillyTavern โดยตรงแต่ไม่ได้อยู่ในไฟล์จะหาย (ดูจำนวนได้ในหน้าต่างก่อนอัปเดต และย้อนกลับได้ในหน้าสรุป) ถ้าไม่อยากเสี่ยงให้เลือก *สร้างเล่มใหม่*
- ถ้า lorebook เดียวกันผูกกับหลายตัวละคร ทุกตัวจะเห็นเนื้อหาใหม่
- lorebook ที่รองรับคือแบบของ SillyTavern ถ้าเป็นของ NovelAI / Agnai / Risu ให้ import ผ่านหน้า World Info ก่อน
- ปุ่ม **ย้อนกลับ** ใช้ได้เฉพาะในหน้าสรุปหลังอัปเดต ปิดหน้าสรุปแล้วย้อนไม่ได้ · ถ้าการอัปเดตสร้าง lorebook ชื่อใหม่ ตอนย้อนกลับ lorebook นั้นยังอยู่ (ลบเองได้) แต่การ์ดจะกลับไปผูกกับเล่มเดิม
- ถ้าบอทกำลังตอบอยู่ ให้รอหรือกดหยุดก่อน
- ไฟล์ .yaml ไม่มีรูป รูปตัวละครจะกลายเป็นรูปเริ่มต้น
- เลขเวอร์ชันแสดงอยู่ข้างชื่อใน Extensions → Card Updater ถ้าอัปเดต extension แล้วหน้าเว็บยังใช้ไฟล์เก่าจากแคช จะมีคำเตือนบอกเวอร์ชันที่ใช้อยู่กับเวอร์ชันบนเซิร์ฟเวอร์ ให้รีเฟรชหน้า (หรือล้างแคชของเบราว์เซอร์)
- ทดสอบกับ SillyTavern 1.19.0
